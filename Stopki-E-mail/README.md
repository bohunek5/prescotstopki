# PRESCOT — Stopki E-mail

[Otwórz podgląd i kopiowanie](https://bohunek5.github.io/prescotstopki/Stopki-E-mail/) · [Pobierz komplet ZIP](https://bohunek5.github.io/prescotstopki/Stopki-E-mail/PRESCOT_STOPKI_ZESPOL.zip)

14 osób i skrzynek, każda z podpisem targowym oraz produkcyjnym. Domyślnie wybrane targi; zatwierdzony granatowy układ. Dane kontaktowe są tekstem HTML, banery pozostają animowane.

## Jak używać

1. W podglądzie wybierz osobę.
2. „Kopiuj stopkę” kopiuje formatowany podpis do treści wiadomości HTML.
3. „Pobierz do Thunderbirda” zapisuje HTML do stałego ustawienia w konfiguracji konta.
4. Pełna instrukcja: [Thunderbird](https://bohunek5.github.io/prescotstopki/Stopki-E-mail/INSTALACJA_THUNDERBIRD.html).

Lokalnie otwórz `START.html`. Podpisy są w folderach `targi/` i `produkcja/`.
