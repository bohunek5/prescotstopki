# PRESCOT LED — kompaktowe stopki

30 propozycji Radka, w tym 5 targowych. Maksymalna szerokość 450 px; banery 144 px / targowe 164 px wysokości. Dane kontaktowe jako tekst HTML; oryginalne fotografie produktów.

- `stopki/NN.html` — podgląd z lokalnymi obrazami.
- `stopki/NN-fragment.html` — fragment podpisu z publicznymi obrazami HTTPS.
- `banery/NN.png` — sam baner, 2× dla ostrych ekranów, wyświetlany na 450 px.
- `podglady/NN.png` — podgląd pełnego podpisu.

Propozycje do akceptacji. Żadnego podpisu nie zainstalowano w skrzynce. HTML korzysta z tabel i stylów inline. Sprawdzono w przeglądarce przy 450 px oraz 320 px; przed instalacją wybranego wariantu potrzebny test w docelowym kliencie poczty, w tym Outlooku.

Galeria: https://bohunek5.github.io/prescotstopki/
