# PRESCOT LED - stopki Radosława Narwojsza

30 propozycji pełnych podpisów i osobnych banerów. Wyłącznie oryginalne fotografie produktów PRESCOT.

Galeria: https://bohunek5.github.io/prescotstopki/

Uruchomienie lokalne: `python3 -m http.server 4277`.

Propozycje do akceptacji. Przed instalacją podpisu należy ustalić docelowe adresy obrazów i sprawdzić wybraną wersję w używanych programach pocztowych.

Materiały i znaki towarowe PRESCOT.
